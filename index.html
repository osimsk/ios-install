Мои приложения

Установка приложений на iPhone через системный механизм iOS.

Если приложение было получено через определённый Apple ID, перед первым запуском войдите в него только через Настройки → Apple Account → Контент и покупки.

Как установить

1. Откройте страницу в Safari.
2. Нажмите «Установить».
3. Подтвердите системное окно iOS.
4. После установки откройте приложение хотя бы один раз.
Страница только открывает itms-services:// с вашим manifest.
